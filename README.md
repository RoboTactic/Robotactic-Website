# RoboTactic

منصة الموقع الإلكتروني لفعالية **RoboTactic**، وهي فعالية تجمع طلاب المرحلة الثانوية والجامعات في مسابقات روبوتات تطبيقية، وورش عمل، ومعرض للمشاريع الطلابية.

> **ابتكار يقوده التفكير**

## الهدف

يهدف RoboTactic إلى:

- تنمية المهارات التقنية والهندسية لدى الطلاب.
- دعم الابتكار والعمل الجماعي والتنافس الشريف.
- ربط المعرفة الأكاديمية بالتطبيق العملي.
- اكتشاف المواهب والمشاريع الطلابية الواعدة وإبرازها.

## نطاق الموقع

### الواجهة العامة

الموقع يقدّم معلومات الفعالية للزوار من دون الحاجة إلى إنشاء حساب، ويتضمن:

- الصفحة الرئيسية: تعريف بالفعالية، عداد تنازلي، وآخر التحديثات.
- المسابقات: مسارات الروبوتات الجامعية، المبتدئين (Controller)، وCanSat / Rockets (Simulation).
- ورش العمل: التفاصيل، المواعيد، المقاعد المتاحة، وروابط التسجيل.
- معرض المشاريع: عرض المشاريع المقبولة والمؤكدة مع البحث والتصفية.
- الرعاة والشركاء، ومركز المساعدة والأسئلة الشائعة.
- دعم العربية والإنجليزية مع اتجاه RTL/LTR مناسب للغة المختارة.

تتم عمليات التسجيل ورفع الملفات عبر نماذج خارجية مثل Google Forms. في النسخة الأولى، لا تُخزَّن بيانات المشاركين الشخصية داخل الموقع.

### الواجهة الداخلية

تُخصَّص لفريق الفعالية وتُدار بالصلاحيات التالية:

| الصلاحية | المسؤوليات |
| --- | --- |
| Super Admin | الوصول الكامل لإدارة المحتوى والمسابقات والورش والمشاريع والإعدادات. |
| Competition Manager | إنشاء المسابقات وتحديثها ومتابعة الفرق المسجلة. |
| Workshop Manager | إنشاء ورش العمل وتحديثها ومتابعة المسجلين. |

## هيكل المشروع

```text
Robotactic/
├── backend/
│   ├── config/          # إعدادات البيئة والتطبيق
│   ├── controllers/     # معالجة طلبات API
│   ├── database/        # ملفات الاتصال والمخططات وقاعدة البيانات لاحقًا
│   ├── middleware/      # المعالجات المشتركة والأخطاء والصلاحيات
│   ├── routes/          # تعريف مسارات API
│   ├── services/        # منطق الأعمال والتكاملات الخارجية
│   ├── utils/           # أدوات مساعدة مشتركة
│   ├── .env.example
│   ├── .gitignore
│   ├── package.json
│   └── server.js
└── frontend/            # محجوز لتطبيق الواجهة
    ├── .gitignore
    └── .gitkeep
```

## تشغيل الباك إند

يتطلب المشروع Node.js 20 أو أحدث.

```powershell
cd backend
npm install
Copy-Item .env.example .env
npm run dev
```

يعمل الخادم افتراضيًا على `http://localhost:3000`، ويمكن التحقق منه عبر:

```text
GET http://localhost:3000/api/health
```

الاستجابة المتوقعة:

```json
{
  "status": "ok",
  "service": "robotactic-backend"
}
```

## حالة التطوير الحالية

- الهيكل الأولي للباك إند جاهز، مع مسار صحة تجريبي ومعالجة للأخطاء.
- مجلد `database` موجود لكنه لا يرتبط بقاعدة بيانات حتى يتم اختيار التقنية.
- مجلد `frontend` متروك فارغًا وظيفيًا ليبدأ تطوير الواجهة عليه لاحقًا.
